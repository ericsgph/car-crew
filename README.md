# CARCREW Vito Cruz website

A fast, maintenance-free static website. It uses plain HTML, CSS, and JavaScript—there are no subscriptions, databases, build steps, or frameworks to maintain.

## Update content

Open `content.js` in any text editor. You can update service cards, the Facebook booking link, and the Google Maps link in one small file. Save it and re-upload the site files to your host.

## Publish for free

The simplest options are **Cloudflare Pages**, **Netlify**, or **GitHub Pages**. Upload this folder (or connect its GitHub repository); set no build command and publish the root directory.

Before publishing, replace the booking link in `content.js` with the shop’s preferred Facebook Messenger, booking, or phone link if needed.
